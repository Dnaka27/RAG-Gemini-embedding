    How it works

    This app uses retrieval-augmented generation (RAG): it finds the passages of your document that match your question, then asks the AI to answer only from them. Numbers below are from this session.

    When you upload

    1. 1ReadUTF-8 text, or pypdf for PDFs.--
    2. 2SplitOverlapping passages that end on whitespace.--
    3. 3Embed{{ config.embedding_model }}, {{ config.dim }} dimensions per passage.--
    4. 4IndexIn memory, per session, up to {{ config.max_chunks }} passages.--

    When you ask

    1. 1Embed the questionSame model, search-query mode.--
    2. 2RetrieveCosine distance, top {{ config.top_k }} passages.--
    3. 3Generate{{ config.generation_model }} answers from those passages only.--

    The 3D cloud

    Each passage's {{ config.dim }}-dimension embedding is reduced to 3 axes with PCA, computed in Python on upload. The lines follow the real ranking in the full space, so two dots can look close in 3D without being retrieved.
